# صيدلية الحداد التعليمية — خريطة الموقع

موقع ثابت (HTML + CSS + JavaScript + Leaflet) بلا Backend ولا قاعدة بيانات ولا مفاتيح API.

## النشر على Cloudflare Pages
ارفع هذا المجلد كما هو (Framework preset: None، Build command: فارغ، Output directory: `/`).
ملف `_headers` يضبط التخزين المؤقت وإذن الموقع الجغرافي.

## التعديل
كل المحتوى في `js/config.js`:
- الاسم والوصف والعنوان بالعربية والإنجليزية، والهاتف/الموقع الإلكتروني (`null` = مخفي).
- نقاط الاهتمام (`markers`): الاسم، النوع، الإحداثيات، الأيقونة (`pharmacy|building|statue|bridge|hospital`)، اللون، الحجم.
- مزوّدو صور الخريطة (`layers`) — غيّر الرابط هنا فقط عند الانتقال لمزوّد آخر أو مدفوع.

## مزوّدو الخرائط
كل الأنماط من خوادم Esri العامة (ArcGIS Online) بلا مفتاح API: هجين، قمر صناعي، عادي، فاتح مبسّط، داكن، تضاريس.
راجع شروط استخدام Esri عند الاستخدام التجاري المكثف. لتغيير المزوّد عدّل `layers` في `js/config.js`.

## الملفات
- `index.html` — الهيكل
- `css/style.css`, `css/fonts.css` — التصميم والخط (Cairo مضمّن في `fonts/`)
- `js/config.js` — الإعدادات والنصوص
- `js/app.js` — منطق الخريطة
- `vendor/leaflet/` — Leaflet 1.9.4 (BSD-2)
- `assets/` — الشعار والأيقونات

## تحسينات الجولة الأخيرة
- **الاتصال/واتساب/الدوام:** في `js/config.js` ← `business` (`phone`, `whatsapp`, `hours`, `photo`).
  مثال للدوام: `hours: { open: '09:00', close: '23:00' }` ← تظهر شارة «مفتوح الآن/مغلق الآن» (توقيت بغداد).
- **مسارات محسوبة مسبقاً:** شغّل `node tools/build-routes.mjs` (Node 18+) فيُنشأ `js/routes.js` وتعمل المسارات فوراً ودون إنترنت.
  بدونه يُحسب المسار مباشرة من خدمة OSRM العامة (للتجربة فقط).
- **المشاركة:** استبدل `DOMAIN` في `index.html` (وسوم og:* وJSON-LD) بنطاق موقعك، ثم اختبر الرابط في واتساب.
- **عند تعديل أي ملف:** غيّر رقم `?v=` في روابط `index.html` ثم حدّث الصفحة تحديثاً إجبارياً.
